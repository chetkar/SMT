The above code implements sequential multiple testing for estimating the number of blocks or communities in SBMs.\\
The advantage of our approach is that it is relatively more resistant to the noise (or out-in ratio).\\
Our method can be paired with the likelihood approach for noisy biomedical data to extracts network that resemble like SBMs.\\
